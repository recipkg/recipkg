# 软件到提示词

## 输入

软件目录、仓库或产品说明，以及用户希望保留的行为。

## 步骤

1. 使用 `recipkg extract <target>` 生成标准任务提示词，再依照提示词分析软件；该命令本身只输出提示词。
2. 记录观察版本、来源、许可、公开行为、接口、边界条件及未知项。
3. 编写 `RECIPE.md`、`BUILD_PROMPT.md` 和需要的 Markdown 验收说明；递归提炼每个必需的软件依赖。
4. 区分配方依赖、参考资料和外部运行前提。不要把普通源码仓库当作现成配方。
5. 用 `recipkg pack <package> -o <name>-<version>.recipe.tar.gz` 收齐依赖并打包，再用 `recipkg check <archive>` 检查归档；依赖都已在本地时也可直接检查配方目录。

## 输出与验收

交付仅包含 UTF-8 `.md` 的配方目录。另一个 Agent 应能从这些文件了解重建目标、全部依赖和验收方法。缺失或推断内容必须显式标记；不承诺从有限观察还原全部原软件行为。
