# 重建 Hello 命令行软件

## 目标

生成一个可从终端调用的程序，文档中将它记为 `hello`。实现语言不限；交付能够在目标环境中复现的安装或启动步骤。程序不使用网络，不读写用户数据文件。

## 命令行行为

- 没有参数时，使用空名字调用 `greeting` 组件。
- 只有一个普通参数时，把整个参数作为名字交给 `greeting`。Shell 已完成引号处理；不要再次拆分参数中的空格。
- 唯一参数为 `--help` 时，标准输出写入 `Usage: hello [name]`，末尾恰好一个换行，退出状态为 0。
- 名字以短横线开头时允许作为普通名字；除独立的 `--help` 外，不解析其他选项。
- 有两个或更多参数时，标准输出为空；标准错误写入 `error: expected at most one name`，末尾恰好一个换行，退出状态为 2。
- 正常问候写到标准输出，末尾恰好一个换行，标准错误为空，退出状态为 0。

## 组件约定

使用依赖 `greeting` 的行为约定。可以把组件实现为函数、模块或其他适合目标语言的结构，但不能省略其递归依赖中的名字规范化规则。

## 验收

以下表格中的参数是已经由 Shell 分割的参数列表；`[]` 表示没有参数。输出栏展示换行之前的内容，正常输出均须以一个换行结束。

| 参数列表 | 标准输出 | 标准错误 | 退出状态 |
| --- | --- | --- | --- |
| `[]` | `Hello, world!` | 空 | 0 |
| `["Ada"]` | `Hello, Ada!` | 空 | 0 |
| `["  Ada   Lovelace  "]` | `Hello, Ada Lovelace!` | 空 | 0 |
| `[""]` | `Hello, world!` | 空 | 0 |
| `["你好"]` | `Hello, 你好!` | 空 | 0 |
| `["--help"]` | `Usage: hello [name]` | 空 | 0 |
| `["-Ada"]` | `Hello, -Ada!` | 空 | 0 |
| `["Ada", "Lovelace"]` | 空 | `error: expected at most one name` | 2 |
