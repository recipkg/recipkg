# 重建 Greeting 组件

## 输入输出

组件接收一个 Unicode 字符串，使用 `text-rules` 依赖的规范化规则取得名字，然后返回 `Hello, `、规范化名字和 `!` 三部分按顺序连接得到的字符串。

返回值本身不附加换行，不写标准输出，不访问网络或文件，不修改输入。不限定函数名、模块组织或实现语言；上层软件必须能调用这个行为。

## 验收

| 输入 | 返回值 |
| --- | --- |
| `Ada` | `Hello, Ada!` |
| 空字符串 | `Hello, world!` |
| 两个空格、`Ada`、三个空格、`Lovelace`、两个空格 | `Hello, Ada Lovelace!` |
| `你好` | `Hello, 你好!` |
| `A!` | `Hello, A!!` |

不要改写名字中的大小写、标点或 Unicode 字符。必须保留 `text-rules` 对空白字符范围的精确定义。
