# 重建名字规范化组件

## 行为

输入为 Unicode 字符串。这里的“空白”只指四种字符：普通空格 U+0020、水平制表符 U+0009、换行 U+000A 和回车 U+000D。

1. 删除开头和结尾连续的上述空白。
2. 将剩余内容中每一段连续的上述空白替换成一个普通空格 U+0020。
3. 如果结果为空，返回字面字符串 `world`；否则返回处理后的名字。

其他字符原样保留，包括大小写、标点、中文、表情符号和不间断空格 U+00A0。不执行 Unicode 规范化或区域相关的大小写转换。

组件不产生副作用，不访问外部服务，不限定实现语言。它没有其他配方依赖。

## 验收

| 输入说明 | 预期结果 |
| --- | --- |
| 空字符串 | `world` |
| 仅包含普通空格、制表符、换行和回车 | `world` |
| `Ada` | `Ada` |
| 普通空格、`Ada`、制表符、换行、`Lovelace`、回车 | `Ada Lovelace` |
| `你好` | `你好` |
| `A`、U+00A0、`B` | `A`、U+00A0、`B`，三个字符原样保留 |
| 一个 U+00A0 | 一个 U+00A0，不变成 `world` |

对任何输入重复规范化，第二次结果应与第一次相同。
